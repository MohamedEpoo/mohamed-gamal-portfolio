# بورتفوليو محمد جمال

بورتفوليو شخصي بـ Angular، يدعم العربية والإنجليزية، ويعرض المشاريع والمهارات وطرق التواصل.

## التشغيل محليًا

```powershell
npm ci
npm start
```

افتح `http://localhost:4200`.

## النشر

يُبنى الموقع ويُنشر تلقائيًا إلى GitHub Pages عند كل تحديث لفرع `main` عبر GitHub Actions.
إعدادات GitHub Pages في المستودع يجب أن تستخدم **GitHub Actions** كمصدر للنشر.

## تحديث المحتوى

عدّل النصوص وبيانات المشاريع والمهارات في `src/app/app.ts`، وهي تتضمن النسختين العربية والإنجليزية.
ضع الصور الثابتة داخل `public` واستخدم مسارات نسبية حتى تعمل على GitHub Pages.
